# FitZone Gym — Landing Page
A modern, energetic gym landing page built with pure HTML & CSS. Designed for **FitZone Gym**,a fictional fitness brand,
showcasing trainers, membership plans, a BMI calculator interface, and customer testimonials.

## Live Demo
https://aditigupta1601.github.io/fitzone-gym-landing-page/

## Features
- **Hero Section** — Gym name, tagline, working hours, address, and a "Join Now"
- **About Gym** — Mission statement, facilities list, and years of experience
- **Trainers Section** — 4 trainer cards with photos, specializations, and experience
- **Membership Pricing** — 3 plans (Basic, Premium, Elite) with feature lists
- **BMI Calculator** — Interactive UI for height/weight input (interface only, no calculation logic)
- **Testimonials** — 3 customer review cards with photos and star ratings
- **Contact Form** — Name, email, and message fields
- **Footer** — Contact details and social links

## Responsive Breakpoints
- **Desktop** (> 900px) — 4 trainer cards / 3 pricing cards per row
- **Tablet** (600px – 900px) — 2 cards per row
- **Mobile** (< 600px) — Single-column stacked layout
